# 仓库执行适配

先读取目标仓库 AGENTS.md 与当前 CRP 能力清单。固定源 commit 和工作区基线，区分用户已有改动。所有新核心、迁移、归档和审计执行先在隔离副本验证；原始资料与实际生产目录不作为测试输出。

现已实现可移植核心、隔离事务与恢复、八方法 canonical 查询、迁移复审队列、审计覆盖计算和只读查询服务；这不代表目标 CRP 仓库已切换到新权威。读取[实际操作边界](operations.md)核实本环境安装的入口。没有部署新核心时仍核对现有 crp.py、文稿及审计脚本参数，不编造 submit_change 等服务。

本地具备执行条件时，通过受控脚本做确定性变换与验证，保留 journal、幂等和恢复行为。发布操作必须符合当前任务授权及仓库流程；未发布只报告本地结果，未回读不报告远端验证成功。

按相关检查→边界测试→项目检查顺序验证。新配置附可复现命令，测试只使用虚构语料或明确授权副本，不调用未授权付费模型。并发取证仅使用实际可用的能力，隔离结果由主审合并。
