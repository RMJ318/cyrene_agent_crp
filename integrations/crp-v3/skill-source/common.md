# CRP 3.0 共同契约

## 旧版优先与版本识别

本预览独立命名，不是旧 Archivist／Auditor 的更新包，不能覆盖其安装身份。现有正式流程继续使用目标仓库固定 commit 中的旧 Skill、协议与脚本。

数据格式、Skill 版本、检索实现版本分别核对：`schema_version: 2.0/2.1` 使用旧数据契约；Archivist v2.2 是技能修订号，不是库 schema 2.2；`retrievalV3Enabled` 只选择检索算法，不表示数据已经迁移。`3.0-preview.1` 是预览技能／检索协议版本，`3.0-draft.2` 是未切换生产的 canonical 核心契约，两者不要求写入旧 registry。

普通 RP 不依赖新服务、OAuth、MCP、新数据库或迁移队列。没有这些能力时照常使用 GitHub 旧入口，不据此报旧库损坏。只有原始源、条目或适用证据指纹发生变化，才按旧规则确定受影响审计；不能因代码 update 全部作废。

## 权威与证据

原始转录与既有文稿的字节、稳定 ID、坐标及历史审计内容受保护。派生摘要、向量、关系导航和接续包可重建，不能成为第二套正文。重构不重签发历史 PASS；指纹绑定的原条目及证据用原规则验证，迁移仅映射引用。

事件发生、主张为真、人物相信和作者查档分别表达。知识取得绑定人物、现实、分支、取得时间、目标版本及范围。TITLE_ONLY 不授权全文；RECEIVED 不等于 READ_FULL；跨引用不等于跨现实传播。未知、纯 OOC、未来版本和身份未决不自动进入人物知识。用户明确订正仍保留来源与审核范围。

原文混合 OOC 保持原样，派生角色视图只能释放授权内容，不把去 OOC 文本称作逐字原稿。缓存、索引、场所关联和同场人物不授予知识。范围变化使旧查询、投递和上下文缓存失效。

继续遵守仓库当前上下文召回协议与文稿协议。冷启动若要求展示 N 轮双方原文，按实际协议和可用来源读取／展示，不能用摘要替代或伪报完整聊天导出。旧场景、旧人、通信和旧事项触发定向取源；同范围可复用有版本的临时证据包，边界变化失效，不能声称环境提供了后台持久缓存。

## 变更、版本和恢复

只使用实际存在且与当前能力清单兼容的接口。新契约未部署时保持旧入口，不能为了满足新 Skill 执行未经授权的迁移或临时造一套正式数据。

所有正式写入经同一事务入口：固定基线、检查冲突、验证变更、原子发布，再验证并推进水位。同 ID 不同内容进入修订或冲突流程；不强推、不覆盖其他工作。恢复前处理 pending 事务，失败不推进成功状态。不得在一轮操作中混用不同 commit 的证据。

## 模型执行方式

模型能力可关闭，或由当前 ChatGPT、本地模型、明确配置的 OpenAI／OpenRouter 提供。语义辅助结果是候选；权限、源哈希、版本、坐标、审计指纹及事务由确定性核心校验。

ChatGPT 当前会话不是 Cyrene 后台 API，也不是 embedding 服务。Embedding、生成和精排分别选择提供方；不同模型／预处理的向量不混用。关闭本地能力时不探测或加载；禁止网络／全部模型时不通过云端回退绕过设置。

云端调用须已有任务、数据域、提供方和预算授权，只发送必要且已授权内容，不因存在 API key 就启动收费任务。不能自动上传全库、下载模型或跨未批准提供方 fallback。工具错误和日志不暴露密钥、私密正文或内部路径。

## 运行权限与汇报

技能不是发布、部署、日程或模型费用的新授权来源，沿用当前用户明确范围。已有自动任务不重复创建。用户独占人物的言行、内心与选择按当前协议保留。

文件存在、哈希通过、关键词扫描、模拟测试和真实 RP 成功分别报告。工具不可用就记录实际阻塞；中断保留可恢复边界。未登记剩余未知时写 UNKNOWN，不写 0。
